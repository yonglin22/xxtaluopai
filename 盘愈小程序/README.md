# 盘愈 PANYU · 微信小程序（原生）

原生 WeChat 小程序（WXML/WXSS/JS），从已上线 H5 逐页迁移。当前为 **第一阶段：可运行骨架 + 问牌/塔罗核心闭环**。

- **APPID**：`wxc4cb1b6a1c959d58`（已认证 + 微信支付已开通）
- **设计系统**：米白玻璃 + 暗金 + 衬线（与 H5「盘愈风」一致，见 `app.wxss`）

## 如何运行
1. 打开「微信开发者工具」→ 导入项目 → 选择本目录 `盘愈小程序/`。
2. AppID 填 `wxc4cb1b6a1c959d58`（已写入 `project.config.json`）。
3. 首次运行：详情 → 本地设置 → 勾选 **「不校验合法域名」**（因为 `wx.request` 要连后端 `taluo-b76.pages.dev`）。
4. 编译即可预览。

## 审核类目建议（重要）
小程序对「占卜 / 塔罗 / 算命」类目审核极严，个人及多数主体会被驳回。建议：
- **主类目**：`教育 / 在线教育` 或 `工具` 下的 **心理咨询 / 情绪测评** 方向；若可选 `医疗健康 - 心理` 需资质，谨慎。
- **推荐路线**：按 **「文化娱乐 / 心理测评（自我认知、情绪测评、性格测试）」** 或 **「工具 / 效率」** 报类目，产品定位统一为 **「自我探索 · 情绪疏导 · 心理陪伴」**（本项目文案已如此），全程弱化「占卜 / 算命 / 预测吉凶」等字样，塔罗/星盘表述为「自我觉察工具、性格与情绪的镜子」，并在每页保留免责声明「仅供自我觉察，不构成确定性预测 / 医疗建议」。
- 名称与简介避免「算命 / 占卜 / 预测未来」；用「心理陪伴 / 情绪 / 自我探索 / 性格测评」。
