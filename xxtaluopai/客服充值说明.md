# 客服充值（后台开通）操作说明

**用户侧流程**：小程序「我的 → 充值」选套餐 → 出**订单号** → 扫你的收款码付款 → 加你微信发「**付款截图 + 订单号**」（手机号选填）。
**你（客服）核对到账后，在后台把这笔订单开通，用户小程序会自动到账**（页面在轮询）。积分只从后台开通入账，前端永不直接加分。

---

## 开通一笔订单

### 方式一：云开发控制台（推荐，免开发）
1. 微信开发者工具 → **云开发 → 云函数 → `admin` → 云端测试**
2. 测试参数（JSON）：
   ```json
   { "action": "confirmOrder", "outTradeNo": "用户发来的订单号", "adminToken": "你设的 ADMIN_TOKEN" }
   ```
3. 运行 → 返回 `{ ok:true, credits, balance }` 即开通成功，用户自动到账。

**先核对再开通**（可选）：
```json
{ "action": "lookupOrder", "outTradeNo": "订单号", "adminToken": "..." }
```
返回订单金额/套餐/状态/用户当前余额，确认无误再 `confirmOrder`。

**手动加/扣积分**（补偿、退款）：
```json
{ "action": "adjust", "openid": "用户openid", "amount": 100, "reason": "补偿", "adminToken": "..." }
```

### 方式二：管理员在小程序内开通（进阶，二期）
把管理员的 openid 配到 `admin` 云函数环境变量 `ADMIN_OPENIDS`，再做个隐藏管理页调用 `admin`。

---

## 配置（admin 云函数环境变量）
- `ADMIN_TOKEN`：自定义的一串密码，控制台开通时用（务必设，别留空）
- `ADMIN_OPENIDS`：管理员 openid，逗号分隔（小程序内开通才需要，选填）

## 安全
- `confirmOrder` **幂等**：同一订单重复开通只入账一次（返回 `already:true`），不会重复加分。
- 无 `ADMIN_TOKEN` 且非管理员 openid 调用 `admin` 会被拒（`无权限`）。
